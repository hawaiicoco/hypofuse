# Upstream References

This page lists external sources consulted for ideas and format facts
during the development of hypofuse. No code or text was copied from
any of these sources.

## ROVER (Fiscus, 1997)

**Reference:** Fiscus, J. G. (1997). "A Post-Processing System to Yield
Reduced Word Error Rates: Recognizer Output Voting Error Reduction
(ROVER)." *Proceedings of the IEEE Workshop on Automatic Speech
Recognition and Understanding.*

**Used for:** The conceptual framework of multi-system consensus via
majority voting over aligned hypothesis grids. The progressive
alignment approach and tie-breaking strategies follow the ROVER idea
of selecting the most-voted token at each position.

## Confusion networks (arXiv:1904.08295)

**Reference:** Mangu, L., Brill, E., & Stolcke, A. (2000). "Finding
Consensus in Speech Recognition: Word Error Minimization and Other
Applications of Confusion Networks." *Computer Speech & Language*,
14(4), 373-400. Also referenced via arXiv:1904.08295 for modern
confusion network formulations.

**Used for:** The confusion network representation (sequence of slots
with arc posteriors), the vote-mass posterior estimator, and the
consistency relation between ROVER output and confusion-network 1-best.

## Speech and Language Processing, 3rd edition (SLP3)

**Reference:** Jurafsky, D. & Martin, J. H. *Speech and Language
Processing* (3rd ed. draft). Stanford University.

**Used for:** N-gram smoothing concepts (Katz backoff, Jelinek-Mercer
interpolation), perplexity definition, and the standard Levenshtein
alignment formulation. The textbook describes these algorithms in
general terms; hypofuse implements simplified versions.

## jiwer

**Reference:** jiwer Python library. <https://github.com/jitsi/jiwer>

**Used for:** API conventions for WER/CER computation (error rate as
errors/reference_length, empty-reference handling). hypofuse's
`word_error_rate` and `character_error_rate` produce values consistent
with jiwer for unit-cost alignment, but the implementation is
independent.

## CMU Sphinx / KenLM ARPA format

**Reference:** CMU Sphinx ARPA LM format documentation; KenLM
<https://kheafield.com/code/kenlm/>

**Used for:** The ARPA file layout (`\data\`, `\N-grams:`, `\end\`
sections, log10 probabilities, backoff weights). The `to_arpa` /
`from_arpa` methods follow this well-known format for
interoperability.

## Levenshtein distance

**Reference:** Levenshtein, V. I. (1966). "Binary codes capable of
correcting deletions, insertions, and reversals." *Soviet Physics
Doklady*, 10(8), 707-710.

**Used for:** The dynamic-programming edit distance algorithm used
in `edit_alignment`. The implementation is standard and follows the
classical recurrence.

## Sakoe-Chiba banding

**Reference:** Sakoe, H. & Chiba, S. (1978). "Dynamic programming
algorithm optimization for spoken word recognition." *IEEE
Transactions on Acoustics, Speech, and Signal Processing*, 26(1),
43-49.

**Used for:** The banded alignment restriction in `edit_alignment(band=N)`
that limits the DP to cells where `|i - j| <= band`.

## Bootstrap methods for comparing systems

**Reference:** Bisani, M. & Ney, H. (2004). "Bootstrap estimates for
confidence intervals in ASR performance evaluation." *Proceedings of
ICASSP 2004.*

**Used for:** The paired bootstrap approach used in
`paired_bootstrap_ci` and `paired_bootstrap_p_value`, including the
add-one smoothing for p-values.

---

**Disclaimer:** hypofuse does not claim to reproduce results from any
of the above papers. All experiments in the test suite use synthetic
data generated by `hypofuse.fixtures`. No pretrained models, real
speech corpora, or published benchmark numbers are involved.
